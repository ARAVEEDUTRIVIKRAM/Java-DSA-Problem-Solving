
# Java DSA Problem Solving

A structured collection of Java programming fundamentals and Data Structures & Algorithms practice problems.

## Objective

To strengthen problem-solving skills, understand algorithmic thinking, and prepare for entry-level software engineering interviews using Java.

## Topics Covered

### Level 1 – Java Fundamentals
- Input and Output
- Conditional Statements
- Loops
- Arrays
- Strings
- Methods
- Mathematical Problems

### Level 2 – Basic DSA
- Arrays
- Strings
- Searching
- Sorting
- Two Pointers
- Hashing

### Level 3 – Intermediate DSA
- Recursion
- Linked Lists
- Stacks and Queues
- Binary Search
- Trees

## Problem Documentation

Each solution aims to include:
- Problem statement
- Sample input and output
- Logical approach
- Java implementation
- Time complexity
- Space complexity

- LeetCode
- HackerRank
